# 페이지 구조

- **Landing.tsx**: 비로그인 랜딩 (히어로 + CTA)
- **Dashboard.tsx**: 로그인 후 메인 대시보드 (프로젝트 인사이트, 통계)
- **ConsultPage.tsx**: 대화형 AI 맞춤 상담 (크리에이터 유형별 질문 → 분석)
- **ScriptAnalysis.tsx**: 크리에이터 유형별 직접 분석
- **ProjectCreate.tsx**: 프로젝트 생성 위저드
- **ProjectDetail.tsx**: 프로젝트 상세 + 탭 (분석/비용/시간/트렌드/목표/시뮬/리포트)
- **ProjectList.tsx**: 프로젝트 목록
- **ProjectEdit.tsx**: 프로젝트 수정
- **ChatPage.tsx**: AI 챗봇 (프로젝트별)
- **BoardListPage.tsx**: 커뮤니티 목록
- **BoardWritePage.tsx**: 게시글 작성
- **BoardDetailPage.tsx**: 게시글 상세 + 댓글
- **AdminPage.tsx**: 관리자 대시보드 (통계, 사용자/게시글 관리)
- **Login.tsx**: 로그인
- **Signup.tsx**: 회원가입
